# TyEditor 路线图

## 阶段 1：可日常使用的编辑器（已完成）

- `TTyForm` + Titlebar 菜单 + 多标签编辑。
- 会话保存/恢复：未保存内容、光标、选区、滚动、编码、EOL、语言、书签、折叠。
- 编码与换行符：UTF-8/16/32、ANSI/GBK/Big5/Shift-JIS 等，状态栏查看/转换/按编码重载。
- 文件操作、关闭标签提示、关闭最后标签退出、无权限打开/保存错误处理。
- 查找/替换、在文件中查找/替换、结果面板跳转。
- 书签、转到行、宏录制/回放、列选择/多光标、常用编辑命令。
- EControl 语法高亮、8 套编辑器配色方案（每套浅/暗）、主题化滚动条、TyControls 主题、单窗口分类设置。
- Linux Qt6 与 Windows i386/Win32 构建，输出到 `dist/`。

## 阶段 2：Notepad++ 核心功能对齐

目标：覆盖 Notepad++ 日常高频功能，优先补齐“会用但还没有”的能力。

详细可执行计划见 [PHASE2_PLAN.md](PHASE2_PLAN.md)，任务与验收记录见 [PHASE2_TASKS.md](PHASE2_TASKS.md)。

1. **会话与备份**
   - 可配置快照间隔/备份目录/保留数量。
   - 崩溃恢复提示与“恢复上次会话”入口。
   - 关闭标签/全部关闭的保存策略统一。

2. **编码**
   - 自动检测 GBK/GB18030、Big5、Shift-JIS、EUC-KR 等常见非 UTF-8 文件。
   - 每个文件的编码历史与“最近使用编码”。
   - BOM 增加/移除、按编码批量重新载入。

3. **查找**
   - 查找历史、正则替换预览、选区查找结果面板。
   - 在文件中查找的异步执行、进度、取消、包含/排除目录。
   - 查找全部结果导出。

4. **编辑**
   - 列编辑模式、多光标菜单化、缩进参考线、括号匹配、自动补全。
   - 行操作补齐：拆分/合并、排序选项、去重、移动行、剪贴板历史。
   - 每语言 Tab/缩进覆盖。

5. **宏与书签**
   - 宏编辑器、宏快捷键、鼠标操作录制（可选）。
   - 书签列表、书签分组/颜色、书签持久化设置。

6. **界面**
   - 标签右键菜单、标签固定、标签溢出菜单。
   - 分屏/双视图、文档地图、全屏/专注模式。
   - 自定义配色方案编辑器/导入导出（当前已内置 8 套浅暗配色，设置位置见 README）。

7. **系统集成**
   - 最近文件、命令行参数、文件管理器拖放完善。
   - 单实例、文件关联、Windows 安装包。
   - 只读属性、网络路径、长路径测试。

## 阶段 3：高级扩展

- UDL 自定义语言。
- 插件 API 与插件管理器。
- 脚本接口（Python/Lua）。
- 文件比较、拼写检查、工程/工作区。
- 内置终端、LSP/诊断面板。

## 阶段 4：发布质量

- 安装器、便携版、自动更新。
- 崩溃日志与可选的错误上报。
- 可访问性、键盘导航、DPI/高对比度。
- Linux/Windows/macOS 交叉构建与回归 CI。

## 建议的下一阶段优先级

1. 编码自动检测 + 在文件中查找异步化。
2. 标签右键菜单 + 分屏/文档地图。
3. 单实例、文件关联、安装器。
4. UDL 与插件 API。
