# Keyboard shortcuts

Menus show the active shortcuts for the current platform. The table below uses
`Ctrl`; on macOS the windowing layer maps the same menu shortcuts to the
platform command key where appropriate.

## Files and tabs

| Shortcut | Action |
| --- | --- |
| `Ctrl+N` | New document |
| `Ctrl+O` | Open file |
| `Ctrl+S` | Save |
| `Ctrl+Shift+S` | Save all |
| `Ctrl+R` | Reload current file |
| `Ctrl+W` | Close current tab |
| `Ctrl+Shift+T` | Reopen the most recently closed tab |

Double-clicking empty space in the tab bar also creates a new document.

## Editing

| Shortcut | Action |
| --- | --- |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` | Cut / copy / paste |
| `Ctrl+A` | Select all |
| `Ctrl+D` | Duplicate line |
| `Ctrl+Shift+L` | Delete line |
| `Ctrl+Shift+Up` / `Ctrl+Shift+Down` | Move line up / down |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | Indent / unindent |
| `Ctrl+Q` | Toggle comment |
| `Ctrl+B` | Go to matching bracket |
| `Ctrl+Shift+U` / `Ctrl+L` | Uppercase / lowercase |
| `Ctrl+J` | Join lines |
| `Ctrl+Alt+Up` / `Ctrl+Alt+Down` | Add caret above / below |

## Search and navigation

| Shortcut | Action |
| --- | --- |
| `Ctrl+F` / `Ctrl+H` | Find / replace |
| `F3` / `Shift+F3` | Find next / previous |
| `Ctrl+Shift+F` / `Ctrl+Shift+H` | Find in files / replace in files |
| `Ctrl+G` | Go to line |
| `F12` | Show search results |
| `F2` | Toggle bookmark |
| `Ctrl+F2` / `Ctrl+Shift+F2` | Next / previous bookmark |
| `Ctrl+Alt+B` | Bookmark list |

## View

| Shortcut | Action |
| --- | --- |
| `F8` | Toggle read-only document map |
| `F11` | Toggle full screen |
| `Ctrl++` / `Ctrl+-` / `Ctrl+0` | Zoom in / out / reset |
| `Ctrl+Alt+G` | Pin current tab |
| `Ctrl+Alt+A` | Toggle always on top |
| `Ctrl+Alt+D` | Toggle dark theme |

## Macros and settings

| Shortcut | Action |
| --- | --- |
| `Ctrl+Alt+R` | Start/stop macro recording |
| `Ctrl+Alt+J` | Play macro |
| `Ctrl+F9` | Play bound macro |
| `Ctrl+Alt+M` | Open macro manager |
| `Ctrl+Alt+P` | Open Preferences |

## Text-editor defaults

TyEditor uses single-caret, non-virtual-space editing by default. `Ctrl+Alt+Up`
and `Ctrl+Alt+Down` explicitly add carets. Copy/cut with no selection does not
operate on the whole line; this is intentional and can be changed in
Preferences.
